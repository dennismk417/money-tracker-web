# Money Tracker – iPhone version

A home-screen app for iPhone. Your data is saved only on your iPhone.

## Put it online (free, GitHub Pages)
1. Create a new **public** GitHub repository, e.g. `money-tracker-web`.
2. Upload everything in this folder (index.html, manifest.webmanifest, sw.js, the icons folder).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. After a minute it is live at `https://<your-username>.github.io/money-tracker-web/`.

## Install on iPhone
Open that link in **Safari** → Share → **Add to Home Screen** → Add.
Always open the app from the home-screen icon (a Safari tab keeps separate data).

## Update
Upload a new index.html. Your data is not touched. Close and reopen the app to load the update.
